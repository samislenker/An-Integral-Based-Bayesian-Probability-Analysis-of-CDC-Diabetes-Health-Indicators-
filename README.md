CDC Diabetes Risk Analysis

Project Overview
This project explores the relationship between age, BMI, and diabetes risk using data from the CDC Diabetes Health Indicators dataset.

The analysis applies concepts from probability, statistics, and calculus to investigate BMI distributions across different age groups.

Methods
- Python for data cleaning and analysis
- Normal and log-normal probability distributions
- Integration to estimate probabilities
- Comparison of theoretical estimates with observed dataset values
- Applications of Bayesian probability

Repository Contents
- **Python (.py):** Code used for data processing and analysis
- **PDF:** Final project report, including mathematical explanations and results
- **CSV:** Dataset used for analysis, if included

Data Source
CDC Diabetes Health Indicators Dataset, available through the UCI Machine Learning Repository.

Running the Project
Download the Python file and any required datasets. Install the libraries imported by the script, then run the program using Python.
